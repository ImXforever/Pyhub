## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 📘 **Command Reference** | 100+ Python commands with syntax, description, and examples. Categorized (Basics, Strings, Lists, OOP, etc.). |
| ⭐ **Favorites System** | Star your most-used commands. Access them instantly from the Favorites tab. |
| 🔍 **Search & Filter** | Search commands by name, syntax, or description. Filter by category. |
| 🧪 **Interactive Workshop** | Write and run Python code in the browser (Pyodide). 3+ challenges with starter code and solution checking. |
| 📤 **Export** | Export all commands to JSON or CSV for backup, analysis, or sharing. |
| ℹ️ **Detail Modal** | Click any command to open a detailed modal with full syntax, description, and example. Copy syntax with one click. |
| 📱 **PWA Ready** | Install on any device (phone, tablet, desktop) as a native app. Works offline with service worker. |
| 🏆 **Achievement System** | 12+ trophies to unlock. First Command, First Favorite, Search Master, First Run, and more. |
| 🎲 **Random Feature** | Click 🎲 Random to discover a random command. Great for learning new things. |
| 🌓 **Dark Theme** | Built-in dark theme with neon green accents. |
